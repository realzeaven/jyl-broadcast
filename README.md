# JYL Broadcast Website

Static website for JYL Broadcast, including the landing page, bilingual copy, interactive particle background, services, Instagram photo gallery, and contact form.

## Publish

This repository is prepared for GitHub Pages through `.github/workflows/pages.yml`.

After pushing to `main`, enable GitHub Pages in the repository settings with source set to **GitHub Actions**. The site will publish from the root of the repository.

## Contact Form

The contact form is prepared for Netlify Forms.

To receive submissions by email:

1. Deploy the site on Netlify.
2. Open the site dashboard in Netlify.
3. Go to Forms and confirm the `contact` form is detected.
4. Add an email notification for the address that should receive inquiries.

The form fields are stored in Netlify's form submissions dashboard and can be exported later if needed.
